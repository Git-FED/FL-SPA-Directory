# Welcome to FED-SPA Discussions 👋

This file explains the discussion categories. GitHub shows it to anyone
opening the Discussions tab for the first time.

## Categories

**📢 Announcements** — release notes, annual data refresh notices.
Read-only for everyone except maintainers.

**💡 Ideas** — feature proposals before they become formal issues.
Great for "should FED-SPA also do X?" conversations. Remember the three
constraints: no backend, no third-party anything, no tracking.

**💬 General** — anything FED-SPA. Questions about a license, a city, a
parlor that seems wrong — start here.

**❓ Q&A** — marked-solved questions. Answer the question, not the person.

**🙏 Show and tell** — screenshots of FED-SPA on your watch, in your car,
on your weird Linux tablet. We want to see them.

## Ground rules

1. **Never paste subscriber-tier content publicly.** The unlicensed
   watchlist is subscriber-only. Quoting its contents into a public
   discussion breaks the deal that makes the tier possible. Don't.
2. **Be decent.** This is a public-safety utility, not a review site for
   establishments. Complaints about a business belong with the FL DOH,
   not here.
3. **No scraping demands.** The data pipeline is manual and annual on
   purpose. "Just scrape it weekly" proposals will be declined politely
   the first time, tersely thereafter.
4. **No third-party pitches.** No libraries, SaaS, APIs, or "you should
   use X". The project builds everything itself. That's the point.

## Annual refresh schedule

The dataset refreshes once a year (see `ROADMAP.md`). Discussion of
mid-year corrections happens in Ideas; corrections themselves go through
the *Data correction* issue template.
