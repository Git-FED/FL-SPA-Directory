Update frequency Annual

The bundled dataset is refreshed once a year. When a new data file replaces data/licensed.json inside the extension package, these values update automatically after the next browser restart.

Subscriber code

The unlicensed watchlist is encrypted. Subscribers receive a code that decrypts it inside the browser — the code is never sent anywhere, because FED-SPA has no backend.

Heads-up: anything stored in chrome.storage.local sits unencrypted on this machine. Only enable this on a device you control. The stored code is scoped to this extension's storage and never leaves the browser.

About & verify it yourself

FED-SPA data is manually checked against the Florida DOH MQA search portal. License status on this list is a snapshot, not a live feed — always re-verify a specific license on the official portal before relying on it.
